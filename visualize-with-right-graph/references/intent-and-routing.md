# 意图、路由与验收

用最小充分记录。简单任务保留问题、口径和验收答案即可。复杂任务用下列结构，允许未知或空值。决策规则编号对应 [证据账本](sources.md)。

| 字段 | 填写内容 |
| --- | --- |
| audience | 主要读者、专业背景及已有知识。读者差异会改变任务时分开设计 |
| context | 阅读时机、设备、尺寸、可用时间、使用频率和环境 |
| question | 读者实际要回答的问题及已知目标、未知目标 |
| purpose | 探索、解释、监控、诊断、比较、辅助决策。给出主目的 |
| action | 答案可能触发的行动、决策阈值或约束。没有时留空 |
| evidence | 数据出处、覆盖、可支持的陈述、限制及待验证假设 |
| data_semantics | 对象、键、行粒度、字段含义和单位、分母和权重、时间窗口、空间或边关系 |
| constraints | 显式指定图形、交付格式、屏幕空间、技术环境、可用交互和数据访问 |
| success_criteria | 可核验的读者问题、预期答案或操作结束状态 |
| assumptions | 只记会改变设计的未确认前提，注明假设失效时如何改 |

## 澄清和推进（R01–R03）

- **直接做。** 已知读者任务和口径，或歧义只改变可逆细节。例如用户要对比同单位月度销售额，默认按日历月排序。
- **声明假设继续。** 证据足够支持一个合理口径，且改动成本低。例如“先按金额比较，订单数可作为独立视图”。假设会使两组不可比时，保留条件分支，避免发表结论。
- **问一个能改变决策的问题。** 优先问最上游缺口。例如“转化率分母是访客还是会话？目前两种算法会改变排名。”可先检查数据和做有依据的部分。对象、配对键、真实分母或区间定义缺失时，绘图不能替代澄清。
- **用选择题做设计交接。** 仅当受众或交付目标有冲突，或错误选择会造成昂贵返工时使用。呈现一项推荐、一个有实际代价差异的替代方案，以及各自能回答的读者问题。数据与环境明确后直接实现，无需例行审批。
- **保护用户指定要求。** 如果圆面积会妨碍读者辨别微小差距，说明影响，可在请求的图上加准确标签或辅表。若缺边权却要求画定量流向，解释宽度无法确定，提供关系图或等待边权。没有依据时停止结论型表达。

## 数据门槛（R01、R03、R08）

1. **行是什么。** 查主键、重复行、连接基数、采样范围。连接前后核对行数和总量。区分原始观测、汇总值、模拟和预测。前后对比按对象 ID 配对并说明流失，无法配对时只比较组分布。
2. **能否相加或比较。** 区分金额和率、总量和人均、存量和期间流量。月末存量通常不能跨月求和。检查单位、币种、价格口径、曝光量及时间范围。合计率默认按业务定义从分子分母重算，例：总体成功数 / 总尝试数。分母 0 时率未定义。组率的简单平均只回答“等权组的平均率”。
3. **时间与相对指标。** 核对时区、采样间隔、观察窗口、季节、边界与未完成周期。缺失和真实零分别处理。增长率为差额 / 基期值，基期为零时不可算，负基期需解释语义；百分点是比例直接相减；指数必须标基期和基值，保留绝对量入口。
4. **覆盖与变换。** 分组核对样本量、缺失和异常原因；原始与可比子集结果可并列，给出筛选条件。比较汇总与子组方向。对抽样、分箱、平滑、聚合、插值做敏感性核查，必要时展示原始值。组间相关不能凭图归因为因果。
5. **可证范围。** 输出数据支持的粒度、观察差异及合理区间。若仅有均值而缺原始值、计数或区间，明确当前能描述均值，分布、显著性及机制未知。仅有方案时写明所需字段或用显式模拟数据。

## 从业务问题到布局（R02、R05）

- **已知目标查值** → 单值或可检索表。图主要承担模式时，精确值可在直接标签或表中。
- **找到未知目标** → 按范围浏览或开放探索。预设一个有解释力的总览，允许切片和回到总览。诊断“为什么”先拆成找异常、比较子群、追原始记录，再提出待验证解释。
- **识别、比较、概括** → 写出输出对象。例如“找超阈值的线路并比较同窗近 30 天变化”。若一组尺度能完成主任务，用单图；若需保留总量和构成、总体与分组等不同分母或尺度，用对齐组合视图。
- **解释** → 明确阅读顺序；**监控** → 状态和异常先于细节；**决策** → 并列选项、约束与不确定性；**探索** → 可从问题或总览开始。多个目的冲突时确认主读者和主任务，或拆视图。
- 两三种候选足够。先淘汰口径失真、缺少关键数据或主任务无法完成的设计，再比较关键值可比性、分布/异常/区间保留、读者时间、屏幕密度、交互与维护成本。无校准时用具体取舍，不打伪精确分数。

## 验收与回退（R09）

| 层级 | 要做的检查 | 失败回到 |
| --- | --- | --- |
| 数据正确 | 从原始行复算代表值和边界值，核对图、标签、表、导出和变换参数 | 数据口径、连接或变换 |
| 任务适配 | 用产物实际回答预设问题，核对选择对象、范围、基准和答案 | 意图或任务抽象 |
| 视觉可读 | 在交付尺寸、窄屏或投影条件下实际渲染。查遮挡、截断、颜色和标记、尺度及阅读顺序 | 编码、布局或文案 |
| 交互正确 | 实际操作默认、变更、联动、清空/重置、空数据及适用的异常路径。检查触屏与键盘替代、导出快照 | 状态模型、控件或实现 |
| 理解有效 | 请目标读者独立作答，记录准确性、用时、误读与阻塞 | 根据误读定位至任务、数据、表达或实现 |

状态用通过、失败、未执行或不适用。浏览器运行、视觉检查和人工读者结果分别记录。没有数据、渲染器、交互环境或读者时，仅报告能证明的层级。

复杂任务内部记录问题、数据来源与粒度、公式或筛选、主次编码、布局、交互合同、实际实现环境、证据限制和验收状态。失败时重算并复验所有受影响的下游视图。
