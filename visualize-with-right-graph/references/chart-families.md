<a id="compare"></a>
## 比较与排名（R02、R04、R08）

- **问题与字段。** 谁更大、差多少、能否找到准确值。需要对象 ID、同口径度量、单位及可比期间，率需分母。
- **编码与变换。** 少量对象用同轴横条或点，按值排序，已有业务顺序时保留；配对两值可用哑铃并标差。柱的长度以零为基线，正负值在零两侧。点靠位置比较，可缩窄范围，刻度清楚并核对相对差距是否被夸大。
- **何时切换。** 精确查几个值用数值，多列反复查值用带排序的表。长尾用搜索、分组或可见的头部加全量入口；说明截断与并列名次。大量同类对象只关心模式时用分布。明确区分排名、差额与比值。
- **交互与实现。** 搜索、按指标排序、在全量中定位；排序切换同步标题与单位。测试长标签、并列项和窄屏。

<a id="time"></a>
## 时间变化（R02、R04、R08）

- **问题与字段。** 何时变化、幅度与持续多久。需要真实时间戳或期间边界、度量、采样频率和覆盖。
- **编码与变换。** 趋势用按真实时间间隔定位的点线，离散期间总量可用列，状态持续可用阶梯。未知断点留缺口，若连接稀疏但有效的观测需明确连接含义。累计和当期分开。移动平均标窗口，并保留原始序列或入口。
- **何时切换。** 少量序列共轴，线太多时用同尺度小图、选重点或用范围包络并保留个体入口。绝对量回答规模，增长率回答相对变化，指数化回答共同基期后的相对轨迹。并排保留基值和单位以免误读。不同量纲先试上下对齐或指数化。双轴仅在两组单位与尺度明确、不会借视觉交叉暗示相等或因果且共用时间有价值时考虑。
- **交互与实现。** 缩放或时间刷选适合跨窗口追异常。范围变化更新覆盖、摘要、采样粒度和最新完整期。时区、空档及降采样保极值需要实测。

<a id="composition"></a>
## 构成与贡献（R03、R04、R08）

- **问题与字段。** 谁占多少、谁推动净变化。需定义总体、互斥可加子项和分母。贡献分析另需同口径基期和终期，可复算到净变化。
- **编码与变换。** 少量非负部分可用堆叠柱回答总体与大致构成。横向比较比例用 100% 堆叠配实际总量；重点子项用共轴或直接标值。瀑布用正负增量连接基终值，贡献合计须闭合。少量部分、单一整体、粗略读比例且分母明确时，可保留用户要求的饼图。
- **何时切换。** 两个小部分需要精确比较，换并排条或点。大量类别先按业务合并、保留其他定义和明细入口。存在负值、重叠成员或分母不同，放弃直接加总的面积/100% 堆叠。总量上升与占比下降可同时成立，主问题涉及两者时保留两视图。
- **交互与实现。** 绝对/比例切换要更换轴、标题和分母说明；筛选后明确分母固定还是随筛选变。

<a id="distribution"></a>
## 分布与异常（R04、R08、R10）

- **问题与字段。** 是否有离散、偏态、尾部、峰或极端样本。需要原始值、组、样本量及可用权重。缺原始值时按已有分位数或摘要表达。
- **编码与变换。** 小样本用逐点或抖动点，保留计数。较大样本用直方图、ECDF、箱线或密度图；同口径分箱与尺度，标箱线胡须定义。箱图上的候选异常需按业务核查；非等宽分箱用密度使面积对应质量。
- **何时切换。** 均值相同也可能分布不同，呈现散布。要看尾部阈值比例时用 ECDF 或阈值加计数。小样本慎用平滑密度；大数据逐点遮挡时用分箱或密度，异常另显示。配对变化要用 ID 做差或连线，独立组用并排分布。
- **交互与实现。** 分组筛选、分箱敏感性或异常明细。检查分箱边界、KDE 带宽、缺失排除和有效样本量。

<a id="association"></a>
## 关系与关联（R03、R04、R08）

- **问题与字段。** 两量是否共同变化、哪类驱动、是否有离群点。需同一观测键关联的 x、y 和单位，可选组、权重与时间。
- **编码与变换。** 散点用两个位置通道；用分面或稀疏色组识别子群。整体拟合与分组关系可能反向；先核查配对键、混杂、范围和拟合假设。
- **何时切换。** 重叠使点不可计数时用透明度、二维分箱或密度，并单列稀有点或用明细。大量变量用带有效 n 的矩阵找候选关系，再查看代表散点。对数仅用于合适的正值域和倍率问题；零或负值单独处理并说明。
- **交互与实现。** 刷选联动明细、分组或粒度切换。稳定 ID 区分重复坐标；趋势线标方法及覆盖，关联用语不超出研究设计。

<a id="space"></a>
## 空间模式（R02、R04、R08）

- **问题与字段。** 邻接、距离、聚集或路径是否回答问题。需地理实体键或坐标、边界/投影及时间；比较区域率需人口、曝光等分母。
- **编码与变换。** 区域率可用分级设色，显示区间划分、缺数和小分母。绝对量可用比例符号或按区比较。点密集用空间聚合，注明半径或网格尺度。
- **何时切换。** 地理仅是分类、任务是排序或查值时用条或表；若用户同时要求地图，可组合排名和位置。地区面积和人口不等，避免把大面积色块读成大量事件。
- **交互与实现。** 地名搜索、尺度切换、范围选择。检查地理连接漏配、投影、边界时效、颜色、底图授权及离线可用性。静态图要保留尺度和图例。

<a id="flow"></a>
## 流向与迁移（R02、R03、R08）

- **问题与字段。** 什么从哪到哪、多少、何时。需源、目的、可解释的权重和单位，最好有批次或窗口及路径去重定义。
- **编码与变换。** 少量路径可用宽度编码的 Sankey/分期转移图，检查节点流入流出、存量/损耗与重复计数。比较精确的起终点对用带量值的 OD 矩阵或表。
- **何时切换。** 普通关系、共现或无权连接用关系图或邻接矩阵，线宽保持一致。边很多时先聚合或用矩阵，明确被隐藏的流量；地理路径重要时再考虑地图。
- **交互与实现。** 点击源或终点追踪路径、查看分母和残余。复杂布局需验证顺序稳定、交叉可读和小流可查。

<a id="hierarchy"></a>
## 层级与网络（R02、R04、R08）

- **问题与字段。** 找祖先/子节点、连接、群组或量级。需节点和边的 ID 与含义；树还需验证父子关系、环与多父；加权另定义可加度量。
- **编码与变换。** 层级路径用缩进树或树图。树状矩形适合粗略看份额和深度有限的层级，精确比较用排序条或表。稀疏网络可用节点连线，稠密网络可用重排邻接矩阵。图布局距离通常只反映算法与布局约束。
- **何时切换。** 多父或循环用一般网络。层级聚合必须先解决重复归属；无法解释的中心性避免写成重要程度。
- **交互与实现。** 搜索、邻居高亮、展开/折叠及面包屑。需稳定键、可重复布局、长标签和密集触点检查。

<a id="interval"></a>
## 区间与不确定性（R03、R08）

- **问题与字段。** 估计多精确、结果范围可能多大、是否越过阈值。需点估计、上下界、区间类型、水平、样本量或模型条件。
- **编码与变换。** 独立估计用同轴点区间，序列可用带状区间。预测从观察期分开，标预测起点；SD、SE、置信区间、预测区间、分位区间和情景范围各自标注。分析对比时优先展示差值及其有依据的区间。
- **何时切换。** 原始小样本用点和 n；区间定义不明则标原字段语义未确认，避免解释成精度、显著性或风险概率。不能从单独区间重叠直接推断差异是否显著，也不能从点估计生成虚假区间。
- **交互与实现。** 显示方法、假设和明细；筛选时重算该范围的有效 n 和区间，或明确区间只适用于总体。验证单/双侧、尺度转换及上下界。

<a id="science"></a>
## 科学与工程（R03、R08、R10）

- **问题与字段。** 要读场的梯度、相界、响应面、传感器特征还是组成边界。先确认领域约定、物理量纲、测量精度、采样网格或几何，判断需要专业复核的部分。
- **编码与变换。** 读固定响应水平用二维等高线或热图配色标；读实际空间形状时可用三维和正投影视图。三组分确属同一闭合总体且和为 100% 时可用三元图。信号频谱注明采样率、窗口、变换和幅度定义。
- **何时切换。** 稀疏不规则采样先给测点或剖面；若插值，标方法、覆盖与外推限制。要求精确读取时给二维剖面或表。三维遮挡、透视和颜色尺度必须接受实际视角检查。对数坐标需明确倍率意义。
- **交互与实现。** 切片、探针、缩放和等值线切换应服务于领域问题。工具支持插值、网格和导出只是实现前提；需核对算法和边界，保留静态剖面或读数入口。
