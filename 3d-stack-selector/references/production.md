# 实施与验收

只读取与当前任务相关的部分，按风险和用户要求确定验证深度。工具命令和 API 随版本变化，使用前检查本地安装和官方文档，不虚构安装、运行或结果。

## 构建通用流程

1. **契约**：列出主体、构图/尺寸、风格、目标环境和产物；设定可观察的验收点。参照图/网站只记录可见事实，未知背面、尺度和交互单独标注。复杂任务先锁定主体轮廓和尺度，不要一开始堆细节。
2. **场景骨架**：明确单位与坐标，创建有语义的层级、参数和可重复入口。生成资产保留原工程、随机种子和必要依赖。先用简化形体确认构图和运行。
3. **几何与材质**：建立主体与相对关系，再逐层补充次要物件、表面和照明；检查法线、UV、穿插、接触和尺度。复用资产时查明来源并匹配目标场景。
4. **动态与交互**：动画明确时间、关键姿态、运动路径；交互定义触发、状态和反馈；物理明确质量、碰撞、约束及求解参数。区分关键帧动画和经过模拟的行为。
5. **输出**：确定分辨率、帧率/时长、目标格式与依赖；实际导出和在目标端打开。跨工具转换时留意颜色管理、轴向、纹理路径、动画与材质支持。
6. **迭代**：建立固定视角和关键帧，逐轮检查构图、形体、材质、灯光、运动；一次处理影响最大的差异并重新验证。保留用户要求和原有作品，避免覆盖不相关内容。

## 按产物验收

- **模型**：多视角显示、比例/轮廓、关键部件、可编辑性；必要时检查三角面数量、拓扑、法线、材质及贴图，导出后重载。
- **CAD/打印**：单位、关键尺寸、公差、布尔体、封闭性、壁厚及目标工具导入；具体公差由用户和用途决定，不虚设工程合格。
- **网页/游戏**：启动与加载、目标设备和浏览器、相机/交互、关键状态、可见报错、帧率及加载预算；移动端或低性能设备未测时如实写明。
- **静帧/视频**：最终分辨率和画幅、主体、光线、材质、多视角或关键帧；检查动画连续性与输出文件是否可播放。
- **仿真/机器人**：模型在目标模拟器加载，关节轴和范围、初始姿态、碰撞、质量惯量、驱动和时间步；运行代表性动作，区分演示与物理可信度。
- **重建/AI 生成**：检查输入覆盖、伪影、几何质量、背面、纹理与尺度；目标资产格式可导出并重载后才声称可用。
