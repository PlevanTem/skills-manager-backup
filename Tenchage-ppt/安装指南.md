# Tenchage-ppt 技能包安装指南

> 腾讯智慧零售风格 PPT 生成技能包（含腾讯字体）

---

## 📦 技能包内容

```
Tenchage-ppt/
├── SKILL.md                  ← 技能主文档（含字体安装说明）
├── fonts/                    ← 腾讯体字体文件
│   ├── 腾讯体 W3.ttf        ← 常规体（正文使用）
│   └── 腾讯体 W7.ttf        ← 粗体（标题使用）
├── package.json              ← Node.js 依赖配置
├── scripts/                  ← 生成脚本目录
│   ├── build_ppt.js          ← 核心 PPT 生成引擎
│   ├── tenchage_v32_layouts.py ← Python 高级版式引擎
│   ├── qa_screenshot.py      ← QA 截图验证脚本
│   └── ...                   ← 其他辅助脚本
└── templates/                ← 预览模板
```

---

## 🔧 安装步骤

### 第一步：安装技能包

1. 将 `Tenchage-ppt` 文件夹复制到：
   ```
   C:\Users\你的用户名\.workbuddy\skills\
   ```

2. 验证安装：重启 WorkBuddy，输入 `/skills` 查看是否已列出 `Tenchage-ppt`

### 第二步：安装腾讯字体（⚠️ 必须）

> **重要**：不安装字体，生成的 PPT 会排版错乱！

#### Windows 用户

1. 打开文件夹：
   ```
   C:\Users\你的用户名\.workbuddy\skills\Tenchage-ppt\fonts\
   ```

2. 右键点击 `腾讯体 W3.ttf` → 选择「**安装**」或「**为所有用户安装**」

3. 右键点击 `腾讯体 W7.ttf` → 选择「**安装**」或「**为所有用户安装**」

4. 安装完成后，**重启 PowerPoint** 使字体生效

#### macOS 用户

1. 在 Finder 中打开：
   ```
   ~/.workbuddy/skills/Tenchage-ppt/fonts/
   ```

2. 双击 `腾讯体 W3.ttf` → 点击「**安装字体**」

3. 双击 `腾讯体 W7.ttf` → 点击「**安装字体**」

4. 安装完成后，重启 PowerPoint 使字体生效

### 第三步：验证安装

1. 打开 PowerPoint
2. 新建文本框
3. 点击字体下拉列表
4. 查找「**腾讯体 W7**」和「**腾讯体 W3**」
5. 如果能找到，说明安装成功！

## 🚀 使用方法

安装完成后，在 WorkBuddy 中输入：

```
帮我做一个关于 XXX 的 PPT
```

或者：

```
用 Tenchage-ppt 生成一个蒙牛会员方案的演示文稿
```

技能会自动：
- 按腾讯智慧零售视觉规范生成 PPT
- 使用腾讯体 W7/W3 字体
- 输出符合品牌标准的专业演示文稿

---

## 📝 注意事项

1. **字体必须安装**：如果同事打开 PPT 时提示"缺少字体"，说明字体未安装
2. **PowerPoint 版本**：建议使用 Office 2019 或更高版本
3. **技能更新**：当有新版本时，重复"第一步"覆盖原文件夹即可

---

## 🆘 常见问题

### Q: 安装字体后，PowerPoint 中找不到？

**A**: 请重启 PowerPoint。如果仍找不到，尝试：
- 以管理员身份运行 PowerPoint
- 检查字体文件是否完整（右键 → 属性 → 查看文件大小）

### Q: 生成的 PPT 字体显示不正确？

**A**: 说明字体未正确安装。请按"第二步"重新安装字体，并重启 PowerPoint。

### Q: 可以分享给外部人员使用吗？

**A**: 请注意字体版权。腾讯体是腾讯内部字体，建议仅在内部分享使用。
