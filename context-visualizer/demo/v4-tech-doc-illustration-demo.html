DPE 模块层次

RX 方向报文从 MAC 到 MEP 的处理层级

MEP (Micro Engine Pool)
C 可编程处理器子系统 · 4 Quark × 8 CME · RISC-V 架构
PIPE (Pipeline 查表)
4 级子 PIPE · Classify → Profile → EM → WC
PAE (Parser Engine)
P4-like 报文解析 · 提取 256 byte 报文头域段
PB (Packet Buffer)
4MB 报文缓存 · 16 bank × 256KB · 以 cell(256B) 管理
MACIF (MAC 接口)
RX 方向报文接收 · PB 写入和优先级调度

Buffer 详细规格

各 Buffer 的大小、地址范围和用途

Buffer类型大小Cursor 范围说明
PB (Packet Buffer)Input 只读256B (384B 扩展)0 ~ 2047 bit原始报文头 cell，PIPE 透传
MB (Meta Buffer)Input 只读96B = 768 bit0 ~ 767 bit高 512bit = meta，低 256bit = result
RB (Result Buffer)Input 只读查表返回大小-协处理器(LMEM/LCAM/TSE/OCM)返回结果
NHB (New Head Buffer)Output 可写384B0 ~ 3071 bit编辑后的新报文头
NMB (New Meta Buffer)Output 可写96B = 768 bit0 ~ 767 bit编辑后的 meta（mep_pol_result 格式）
KB (Key Buffer)Output 可写变长-组装查表 key 用
⚠️ Cursor 注意事项
每个 Buffer 有独立的 cursor，cursor 单位是 bit（不是 byte！）。支持 set_cursor（绝对寻址）和 add_cursor（相对偏移）两种操作。

微码读取示例

CME 线程中读取 Meta Buffer 的典型代码片段

C / MEP Microcoderead_meta_example.c
// 读取 pipe_mep_meta 中的 src_type 和 src_vif
set_cursor(MB, 0);                  // cursor 定位到 meta 起始
uint8_t  src_type = read_mb(2);     // 读取 2 bit
uint16_t src_vif  = read_mb(14);    // 读取 14 bit

// 跳到 pkt_len 域段
set_cursor(MB, 64);                 // 绝对定位 bit 64
uint16_t pkt_len = read_mb(14);     // 14 bit 报文长度

// 读取 pipe_mep_result 中的 destination
set_cursor(MB, 514);                // result 区 offset 512 + 2
uint32_t destination = read_mb(23); // 23 bit 目的地

// 写 New Meta Buffer (mep_pol_result)
set_cursor(NMB, 0);
write_nmb(1, drop_flag);           // 1 bit 丢弃标记
write_nmb(1, dest_type);           // 1 bit 单播/组播
write_nmb(23, new_destination);    // 23 bit 新目的地
💡 提示
所有 read_mb/write_nmb 操作会自动推进 cursor。如果需要跳转到非连续位置，需先调用 set_cursor。RB 是查表返回结果的读取 buffer，每次 IO 命令返回后自动填充。
