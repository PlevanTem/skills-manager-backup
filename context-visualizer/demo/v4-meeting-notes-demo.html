议题概要

本次会议讨论 4 个核心议题

汇报人：侯翔蔡

Session 表、dev_entry、vport_property 三大核心 API 重构已全部完成。UT 覆盖率从 62% 提升至 98%。建议本周锁定 API 接口，发布 v1.2.0。

决议
Session 表 API 接口正式锁定，v1.2.0 定于 W14 发布。后续接口变更需走 RFC 流程。

汇报人：张三

当前热升级遇到新旧版本 IMEM 格式不兼容问题。提出两种方案：

  • 方案 A — 双镜像切换：同时加载新旧 IMEM，通过 bank 切换实现无损升级。优点是可靠性高，缺点是占用双倍 IMEM 空间。
  • 方案 B — 格式兼容层：在新版微码中增加旧格式解析逻辑。优点是节省空间，缺点是增加代码复杂度。
决议
采用方案 A（双镜像切换）。32KB IMEM 空间充足，可靠性优先。张三负责出详细设计文档，W14 评审。

汇报人：李四

29.20.232.79 仿真环境本周出现 3 次崩溃，根因是 SoC 固件 bug。运维建议切换到 29.98.177.226 正式环境继续测试。

⚠️ 风险
226 环境当前负载较高，需要协调排期。预计下周三可用。
决议
切换到 226 节点。李四协调运维确认可用时间，本周五前反馈。

汇报人：王五

Q2 重点方向：性能优化（目标 10Mpps 转发基线）、CT 状态管理增强、多 Quark 负载均衡。具体排期 W15 定稿。
