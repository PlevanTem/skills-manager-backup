# 跨域桥接检查清单

> 被 SKILL.md Stage 3 BFS 全连通验证引用。当 BFS 发现断连子图时，逐项检查本清单。

## 通用桥接模式

知识图谱中的断连通常发生在**子域交界处**。以下是常见的跨域桥梁类型：

| 桥接模式 | 典型关系 | 断连后果 |
|---------|---------|---------|
| 主体 ↔ 账户 | 主体拥有/绑定账户 | 账户域成孤岛 |
| 主体 ↔ 产品 | 主体持有产品权限 | 产品域断连 |
| 产品 ↔ 交易 | 产品配置决定交易类型 | 交易域断连 |
| 交易 ↔ 账户 | 交易结算→账户操作 | 结算链断裂 |
| 正向单 ↔ 逆向单 | 退款/冲正→原始交易 | 逆向域成孤岛 |
| 账户 ↔ 逆向 | 退款出入账→账户 | 资金链断裂 |
| 主体 ↔ 资料 | 主体定义→资料项类型 | 资料域成孤岛 |
| 枚举 ↔ 领域模型 | 枚举值→父类型实体 | 枚举叶子孤立 |

## 修复策略

1. **首选**：从补充数据源（类图 JSON / 代码外键）中查找缺失边
2. **次选**：从文档文本中提取隐含关系描述
3. **最后**：标记到 `kg-unconnected.md`，报告用户

## 微信支付领域特定桥接

以下为微信支付知识图谱中验证过的关键桥接：

| 桥接 | 典型关系 | 来源 |
|------|---------|------|
| 参与方（B+C） ↔ 商户资金账户 | 参与方绑定账户 | 34-交易领域模型 |
| 产品权限 ↔ 参与方类型 | 权限关联参与方 | 34-交易领域模型 |
| 产品支持的地域及连接模式 ↔ 交易服务类型 | 决定交易服务 | 34-交易领域模型 |
| 交易结算单 ↔ 商户/平台/个人操作单 | 结算触发操作 | 34-交易领域模型 |
| 交易退款总控 ↔ 交易单 | 退款关联原始交易 | 00-退款业务领域建模 |
| 退款出资方/入账方 ↔ 账户 | 退款资金流 | 00-退款业务领域建模 |
| 参与方的定义 ↔ 资料项类型 | 参与方关联资料 | 参与方知识域 |
| AccountType ↔ 个人资金账户类型 | 枚举定义类型 | 个人账户知识域 |
