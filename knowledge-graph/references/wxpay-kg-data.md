## 二、关键业务概念词典（来自名词列表精华提炼）

### A. 核心交易概念

| 术语 | 精准定义 |
|------|---------|
| **支付单** | 付款方发起付款的交易凭证，与交易订单、商品单、渠道单共同组成微信支付的交易订单 |
| **收款下单凭证** | 微信支付返回给商户用于标识下单成功的字符串（包含数字和字母） |
| **标价金额** | 商户指定的交易总金额（单位：最小币种单位），即"订单金额" |
| **支付场景** | 用户发起交易时的系统上下文环境，包括JSAPI/APP/Native/小程序等 |
| **微信支付交易订单号** | 微信支付系统为每笔交易分配的唯一订单号，用于标识原始支付交易 |
| **微信支付场景** | 通过行业场景ID和行业产品ID定义不同业务形态的交易场景分类 |
| **支付有优惠任务** | 用户达到门槛可获得金币的支付有优惠业务形式 |

### B. 退款核心概念

| 术语 | 精准定义 |
|------|---------|
| **微信支付退款资金来源** | 退款操作的资金来源类型：可用余额退款 / 未结算资金退款（仅适用特定结算类型商户）|
| **退款发起时间** | 收款方（商户）发起退款的时间 |
| **首发提现退款** | 由商户代为退款，首次发起退款时把退款资金直接提现到用户或商户的银行卡（用于账户注销场景）|
| **误打款退款申请单** | 错误打款给微信支付备付金账户情况下提交的特殊退款申请单（已下线）|

### C. 结算核心概念

| 术语 | 精准定义 |
|------|---------|
| **结算套餐** | 针对新资金流商户，包含结算周期/计费模式/付款模式/收费方式/生效期间的组合 |
| **结算对象** | 包括交易单（正向结算）和退款单（反向结算）两种 |
| **返佣** | 微信支付给服务商/渠道商的佣金返还，鼓励推广行为 |
| **自然月追溯返佣** | 已过正常计算期，系统从未计算过，进行追溯的返佣 |
| **后收费** | 商户使用微信支付服务后，按约定规则和周期结算，而非实时扣费 |

### D. 商户体系核心概念

| 术语 | 精准定义 |
|------|---------|
| **平台收付通** | 微信支付专为平台商户打造的支付结算解决方案：多个二级商户订单合单支付，资金冻结进入各自账户，平台满足条件后解冻 |
| **超管** | 商户平台最高权限管理员，可执行商户管理、产品授权等核心操作 |
| **运营主体** | 平台商户的用户认知主体，与服务商存在公司/品牌关联，通过法律协议约定业务范围 |
| **开户意愿** | 确认商户真实入驻意愿的环节（法人扫码/开户意愿视频/承诺函），是防范欺诈的关键 |
| **上行打款** | 账户验证机制：商户向微信支付指定账号打款，系统根据打款行为验证身份 |
| **商户API v3** | 微信支付新一代接口规范，采用RESTful+JSON+SHA256-RSA签名，相比v2有显著安全提升 |
| **商户资质** | 商户向微信支付提供的许可证等资质证件 |
| **品牌收款关系** | 品牌门店经营方收款商户号与品牌之间的关系 |
| **子商户评级等级** | 微信支付对子商户信用分类：S/A/B/C/D/T六个主级别及细分级别（如A+/A-等），用于风控决策 |

### E. 营销核心概念

| 术语 | 精准定义 |
|------|---------|
| **优惠ID** | 微信支付优惠活动的唯一标识 |
| **普通券** | 发放库存和核销库存一致（充值型，发X元可核销X元，占商户资金）|
| **代金券类型** | CASH（充值代金券）/ NO_CASH（非充值代金券，微信垫付）|
| **优惠标记(goodstag)** | 商户自定义，下单时传入，批次配置了标记则提交订单需带同样标记才可核销 |
| **低面值代金券** | 官方根据数据计算判定的低于特定面额的代金券/立减/折扣 |
| **全场定额立减** | 无需领券即可享受的固定金额优惠，指定商户所有单品可参与 |
| **代金券批次的境外可用门店** | 代金券核销规则：用户需在指定境外门店发起交易才能核销 |

### F. 支付分核心概念

| 术语 | 精准定义 |
|------|---------|
| **支付分服务ID** | 微信支付分系统中为每个服务分配的唯一ID |
| **服务时间段** | 定义支付分服务的开始和结束时间范围 |
| **服务门槛分数** | 服务粒度设定的分数值：用户分 ≥ 此值可免押金，否则需缴押金 |
| **展示分下限** | 业务规则允许的展示分最小值 |
| **开通极速退款服务最低分数** | 用户开通极速退款所需的展示分最低阈值，由风控策略动态设定 |
| **支付分创结单模式** | 用户申请使用服务时无需与支付分交互，服务结束时商户直接对用户扣款的模式 |
| **免确认页确认订单流程** | 用户使用支付分服务时，商户帮用户创建订单后无需用户在支付分页面确认即可成功的流程 |
| **支付分服务运营账号** | 商户用于管理支付分服务的专用账号，由商户号+AppID唯一确定 |
| **服务管理员** | 被授权管理特定支付分服务的实体角色，通过sp_mchid与支付分服务建立绑定关系 |
| **支付分间连商户收款单号** | 间连模式下支付分系统生成的收款单唯一标识 |

### G. 委托代扣核心概念

| 术语 | 精准定义 |
|------|---------|
| **委托缴付应用** | 接入委托缴付功能的业务（如微信保险服务），为授权该业务的商户提供委托缴付服务 |
| **商户委托缴付** | 商户委托技术服务商定期或按指令发起缴付账单服务 |
| **预计扣费金额** | 商户请求下发预扣费通知时的预计金额，不能低于实际扣费金额 |
| **对公快捷支付协议** | 企业/事业单位等和银行签订的基于对公银行账户的快捷支付协议 |
| **缴付账单** | 定期或按指令缴付不同行业商户的账单（银行业也称"账单缴付"）|

### H. 用户账户核心概念

| 术语 | 精准定义 |
|------|---------|
| **余额预授权** | 财付通核心异常时为部分用户提供的垫资支付服务，零钱暂置最后一位 |
| **冻结支付** | 冻结用户支付账户的出账能力，冻结后不能提现/支付 |
| **零钱通转出退回** | 零钱通赎回失败时自动重新发起申购 |
| **提现到账方式** | 目前只支持提现到储蓄卡 |
| **指纹支付** | 用户在支持指纹验证设备上完成支付的方式 |
| **财付通绑卡序列号** | 用户支付方式的唯一标识（32位/64位字符串），区分不同用户对同一张卡的绑定记录 |
| **客户号** | 基于证件号+证件类型生成的用户唯一编号 |
| **用户真身ID** | 财付通自然人的唯一ID |

### I. 跨境/境外核心概念

| 术语 | 精准定义 |
|------|---------|
| **境外** | 非中国大陆，含港澳台及中国边境以外国家地区 |
| **跨境商户** | 商户所在地是境外，交易在境内，结算币种是人民币（如agoda/apple）|
| **购汇** | 境内企业/个人通过银行用人民币购买外币进行跨境支付的行为 |
| **协议优惠汇率** | 在牌价基础上与银行谈判达成的优惠折让汇率 |
| **超优汇率** | 选取更加优惠的汇率进行换算 |
| **境外钱包用户标识** | 基于境外钱包传入账户标识转换的特殊格式openid |
| **3DS验证** | 国际卡组织开发的在线支付安全协议，多因素认证，常见于跨境/高风险交易 |

### J. 风控安全核心概念

| 术语 | 精准定义 |
|------|---------|
| **反洗钱四条件** | 单笔>1万/30天累计>5万/账户余额连续10天>5000/购买金融产品 |
| **支付限额** | 系统对单笔或单日交易金额设定的上限（由平台/银行按风控/合规要求设定）|
| **银行卡交易限额** | 微信支付根据银行规则/支付业务场景/交易风险等级设置的限额 |
| **支付成功时间限制** | 支付成功状态需在交易发生后24小时内通知 |
| **人脸核验** | 通过人脸识别验证用户身份（反洗钱/重要操作场景使用）|
| **多证件关联** | 同一真实个人持有多种证件，系统归集到同一客户号下统一管理 |
| **同名多账户注销** | 针对同一实名证件注册的多个微信支付账户的注销流程 |

### K. 特殊业务形态

| 术语 | 精准定义 |
|------|---------|
| **缴税收银台** | 专为缴税场景设计的独立收银台，仅支持银行卡，资金不经第三方账户直接划扣缴库 |
| **国库支付** | 政务行业特殊支付，含缴税/社保/财政非税/不动产税费/海关税等 |
| **群收款** | 通过微信群发起的集体收款功能，微信群收款系统独立运营 |
| **速购单** | 转账助手系统中的快速交易订单 |
| **转账助手** | 支持转账/收款统计的系统，包含顾客统计（交易金额/笔数/时间等维度）|
| **业务实现号** | 财付通内部用于过渡客户资金的技术账户，禁止绑卡/充值提现操作 |
| **中转B账户** | 资金划拨过程中用于短暂停留资金的账户 |
| **分付** | 微信信贷产品，支持分期付款 |
| **亲属卡** | 家庭成员共用额度的支付方式 |
| **零花钱** | 家长给未成年子女的账户，含安全锁/支付限制/可穿戴设备支持 |

## 三、系统边界（与外部系统交互）

| 外部系统 | 交互方式 | 业务场景 |
|---------|---------|---------|
| **银行系统（发卡行）** | 银行卡扣款/退款 | 用户绑卡支付/原路退款 |
| **银联/网联（清算机构）** | 跨行清算 | 机构间连交易 |
| **商户ERP/系统** | API接口 | 下单/查单/退款 |
| **微信开放平台** | OpenID获取/JS-SDK | JSAPI/小程序支付 |
| **企业微信** | 企业支付授权 | 企微员工支付场景 |
| **税务系统** | 国库专线 | 缴税收银台 |
| **保险公司系统** | 委托代扣协议 | 保险自动续费 |
| **停车场/高速系统** | 车牌绑定API | 车牌付 |
| **基金公司** | 货币基金申购赎回 | 零钱通申购/赎回 |

## 四、知识图谱关键路径查询表

| 问题类型 | 关键实体链 | 涉及子域 |
|---------|-----------|---------|
| 商户如何收款？ | 普通商户→产品权限→交易服务类型→支付订单←微信用户 | C2B交易/商户基础 |
| 退款资金从哪来？ | 退款单←支付订单→商户基本账户(BASIC/UNSETTLED)→用户账户 | 商业退款/结算 |
| 优惠券如何影响金额？ | 代金券(NO_CASH/CASH)→支付订单.payer_total = 标价金额 - 优惠金额 | C2B交易/营销 |
| 服务商和子商户关系？ | 服务商(sp_mchid)→代理→子商户(sub_mchid)，API含sp+sub双参数 | 商户基础/参与方 |
| 支付分免押怎么判定？ | 用户展示分≥服务门槛分→免押金使用服务 | 支付分系统 |
| 手续费怎么计算？ | 结算金额 = 收款金额 - 无资金流券 - 退款金额；手续费 = 结算金额 × 计费费率 | 结算 |
| 分账资金怎么流转？ | 支付成功+分账标记→资金冻结→发起分账→解冻→入分账方基本账户 | 分账 |
| 平台收付通如何运作？ | 消费者→合单支付→各二级商户账户(冻结)→平台确认收货→解冻→平台收取佣金 | 分账/商户 |
| 如何验证商户身份？ | 入驻申请→法人信息→开户意愿(扫码/视频/承诺函)→上行打款/刷脸→审核通过 | 商户入驻 |
| 用户账户有哪些限制？ | 实名等级(I/II/III类)→年/日消费限额；反洗钱四条件→复核 | 用户信息/实名 |
