## 2. 字体

```css
font-family: 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

## 3. 节点样式

| 实体类型 | symbolSize | fontSize | 边框 | 标签显示 |
|---------|-----------|---------|------|---------|
| 聚合根/核心实体 | 35/28 | 11 | 白色3px | 默认显示 |
| 一般实体 | 15 | 8 | 半透明白1px | 默认显示 |
| 枚举 | 8 | 7 | 半透明白1px | 默认隐藏 |
| 名词 | 10 | 7 | 半透明白1px | 默认显示 |

- 标签统一右置: `position: 'right'`, `formatter: '{b}'`
- 按业务域着色 (DOMAIN_PALETTE, 50色循环)
- 聚合根白色边框: `borderColor: '#fff', borderWidth: 3`
- 其他实体: `borderColor: 'rgba(255,255,255,0.2)', borderWidth: 1`

## 4. 边样式

| 关系类型 | 颜色 | 线型 | 宽度 |
|---------|------|------|------|
| 关联 | `#74c0fc` | solid | 0.8 |
| 泛化/继承 | `#ff6b6b` | solid | 2 |
| 组合 | `#ffd43b` | solid | 0.8 |
| 聚合 | `#69db7c` | solid | 0.8 |
| 枚举归属 | `#868e96` | dotted | 0.4, opacity 0.2 |
| 属于概念 | `#ff922b` | solid | 0.8 |
| 跨域引用 | `#ff922b` | solid | 0.8 |

- 箭头: `edgeSymbol: ['none','arrow'], edgeSymbolSize: [0,4]`
- 弧度: `curveness: 0.08 + (i%5)*0.02` (相邻边错开避免重叠)

## 6. 交互功能

### 6.1 5层BFS高亮

点击或搜索节点后, 从该节点BFS扩展5层:

| 层级 | opacity | size倍率 | fontSize | 标签颜色 | 效果 |
|------|---------|---------|---------|---------|------|
| 焦点 | 1.0 | 1.8x | 13 | #FFD600 | 金色+发光(shadowBlur:25) |
| 1层 | 0.88 | 1.2x | 10 | #c9d1d9 | - |
| 2层 | 0.65 | 1.05x | 9 | #c9d1d9 | - |
| 3层 | 0.42 | 0.95x | 8 | #c9d1d9 | - |
| 4层 | 0.25 | 0.85x | 8 | #c9d1d9 | - |
| 5层 | 0.12 | 0.75x | 7 | #c9d1d9 | - |
| 超出 | 0.03 | 0.4x | - | - | 标签隐藏 |

- 所有5层的标签都保留显示 (`label.show = true`)
- 高亮用发光效果 (shadow), 非加粗 (不使用fontWeight)
- 焦点边: width 2.5, 带shadowColor
- ESC键退出高亮

### 6.2 hover adjacency

ECharts 内置:
```js
emphasis: { focus: 'adjacency', lineStyle: { width: 2, opacity: 1 } }
blur: { itemStyle: { opacity: 0.1 }, lineStyle: { opacity: 0.03 } }
```

### 6.3 工具栏按钮

| 按钮 | 功能 | 切换态 |
|------|------|--------|
| 重置视图 | 退出高亮, 恢复默认 | - |
| 标签 | 显隐所有标签 | 激活=蓝色 |
| 枚举值 | 显隐枚举类型节点标签并放大 | 激活=蓝色 |
| 导出PNG | 下载2x像素PNG | - |

### 6.4 详情面板

- 右上角300px宽, 显示: ID/类型/域/描述/属性/枚举值/备注/出入关系
- 枚举值折叠: ▶/▼ 切换, 最大高度200px可滚动
- 关系列表中实体名可点击跳转

### 6.5 搜索

- 侧边栏输入框, 实时匹配名称/ID, 最多15条
- 点击结果触发5层BFS高亮

### 6.6 键盘

- ESC: 退出高亮 + 关闭详情面板 + 清空搜索
