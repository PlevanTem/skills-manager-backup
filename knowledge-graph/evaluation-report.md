1. **六大组件幻影承诺**（P1）：header 声称六大输出组件，但 YAML 主管道的提取规则、输出格式、验证规则、评分标准和脚本只处理 entities+relations。glossary/businessRules/businessFlows/codeMapping 仅在 JSON Schema（`kg_schema.md`）中定义，从未在任何 Stage 产出。
2. **reference 文件宿主绑定残留**（P2）：v5.0.2 声称"去除宿主绑定表述"，但 `role-matrix.md` 和 `validation-rules.yaml` 中仍含平台路径和 Knot 引用。
3. **文档同步规则覆盖不全**（P2）：同步纪律只约束 SKILL.md/USAGE.md/CHANGELOG.md，references/ 文件变更无同步保障。
4. **kg_validate.py 校验覆盖不足**（P2）：Stage 4 定义 10 项检查，脚本只覆盖 5 项。

**已修复（v5.1.0）：**
- [x] 修正组件声明：YAML 主管道 = entities+relations；JSON 扩展 Schema = 4 个可选辅助组件
- [x] 清理 role-matrix.md + validation-rules.yaml 的宿主绑定残留
- [x] 扩展文档同步规则，新增 references/ 文件扫描条款
